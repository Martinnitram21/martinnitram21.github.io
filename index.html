Featured Projects

Live in production · Solo build · Capstone

AzaBuild — Construction Estimation System

1,700+ Fajardo coefficients 150+ API routes Laravel 12 + React Mobile sync

A quantity takeoff, cost estimation and CPM project management platform I built single-handedly for Azacon Builders and Realty OPC in Davao City, now in daily use by the firm. It runs an interpolation and extrapolation engine over 1,700+ material coefficients from Max Fajardo's Simplified Construction Estimate (1995), backed by a Laravel 12 REST API and a React front end, with task and worker management, weather-aware scheduling and PDF report generation.

Visit azabuild.cids.io
🎓 In development · Commissioned by the Municipality of Sulop

eSkolar+ (LSAS) — Scholarship Administration System

LGU commissioned .NET 10 · WPF CRS + GGMS integration Capstone project

A desktop scholarship management system commissioned by the Municipality of Sulop, Davao del Sur, covering the full scholarship lifecycle — application intake, review, and disbursement. Built on .NET 10 and WPF, it validates beneficiaries against the Civil Registry System, integrates with GGMS for government fund tracking, secures sign-in with email OTP, and generates PDF and Excel reports with in-app preview. Deployed to Hostinger cloud.

Source is private — commissioned by the LGU
